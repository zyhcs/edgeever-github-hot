# 🚀 EdgeEver GitHub Hot Digest (开源热搜日报)

面向 [EdgeEver](https://edgeever.org) 笔记系统的 **GitHub 开源热搜与技术趋势日报插件**。

类似官方的 AI RSS 分类日报，本插件专为开源探索者、系统架构师与技术极客打造：实时聚合 GitHub 开源热搜与飙升榜单，借助 **EdgeEver 客户端原生 AI 模型** 或 **自定义 OpenAI 兼容代理** 深度剖析项目核心痛点、架构选型与技术生态走向，一键生成结构严谨、排版精良的 Markdown 技术日报并自动归档至您的笔记本。

---

## ✨ 核心特性

- 🌅 **昨日开源热搜日报 (Daily Digest)**
  - 聚焦过去 24 小时 GitHub 飙升最快的顶级黑马项目；
  - 自动提炼「解决的核心痛点」、「技术架构与设计亮点」以及「适用场景探索建议」；
  - 每日早晨一键生成或自动调度归档。
- 🚀 **最近一周技术趋势周刊 (Weekly Digest)**
  - 聚合本周开源全景热搜榜 Top 10 ~ Top 20；
  - 提炼 3 条宏观「生态洞察与技术风向标」+ 全景速览表格 + 重点项目全景拆解。
- 🤖 **双引擎 AI 智能解读 (免配置 / 高灵活)**
  - **EdgeEver 原生 AI (推荐)**：直接联动 EdgeEver 客户端配置的工作区大模型（`context.ai.generate`），开箱即用，零额外成本；
  - **自定义 OpenAI 兼容代理**：支持灵活填入个人 DeepSeek、OpenAI、Moonshot 或自建中转 API 端点与 Key。
- 🔥 **实时热榜卡片控制台 (Live Stream)**
  - 内置沉浸式双栏控制台，支持实时预览热榜卡片流（仓库名、作者、语言徽标、Star 增量、原始介绍等）；
  - 支持快捷切换语言分类：**全语言总榜**、**Python (AI/深度学习)**、**TypeScript (现代全栈)**、**Rust (高性能基础设施)**、**Go (云原生微服务)**、**C/C++** 等。
- 📁 **自动保存与智能归档**
  - 生成文章一键保存至指定笔记本（支持自动匹配「GitHub 热榜 / 开源日报」笔记本）；
  - 自动注入分类标签（如 `#GitHub热榜`、`#开源日报`、`#2026-10-03` 等）；
  - 智能防重复机制：同一周期的日报支持无缝原地更新或新立版本。
- ⏰ **定时自动生成 (类似官方 RSS 日报计划)**
  - 支持在设置中开启每日定时任务（如每天上午 `08:30`），在后台自动抓取热榜并通过 AI 撰写日报存入笔记，打开 EdgeEver 即可晨读。
- 🎨 **无缝融入 EdgeEver 交互**
  - 支持将触发按钮嵌入编辑器格式工具栏末尾（原生极简图标，防抖防闪烁），或悬浮在右下角（安全避开原生 AI 按钮）。

## 📥 安装方式

### 方式一：EdgeEver 插件管理器一键安装 (推荐)
1. 打开 EdgeEver，进入 **「设置」 -> 「插件」**；
2. 点击 **「从 GitHub 安装」**，填入本仓库地址：
   ```text
   zyhcs/edgeever-github-hot
   ```
3. 点击安装，插件将自动完成下载与启用！

### 方式二：手动安装
1. 前往本仓库的 [Releases 页面](https://github.com/zyhcs/edgeever-github-hot/releases) 下载最新发行版的 `manifest.json`、`main.js`、`styles.css`；
2. 将这三个文件拷贝至 EdgeEver 插件安装目录即可。

## ⚙️ 设置项指南

| 配置项 | 默认值 | 作用说明 |
| :--- | :--- | :--- |
| **默认榜单统计周期** | `昨日开源热搜日报` | 快捷打开时的默认模式（昨日日报 / 本周周刊） |
| **默认技术分类** | `🔥 全语言总热榜` | 默认拉取的编程语言与技术栈 |
| **精选项目数量上限** | `10` | 每次交由 AI 深入解读的项目数量（5 ~ 20） |
| **AI 总结引擎** | `EdgeEver 原生 AI` | 选用客户端内置 AI 还是自定义代理 |
| **自定义 AI 端点** | `https://api.openai.com/v1` | 自定义代理 Base URL |
| **自定义 AI Key / Model** | - | 对应 API 密钥与模型名称（如 `gpt-4o-mini` / `deepseek-chat`） |
| **每日自动生成日报** | `关闭` | 是否开启后台定时调度自动写作归档 |
| **自动生成时间** | `08:30` | 每天固定触发日报生成的时刻 |
| **入口按钮位置** | `嵌入编辑器工具栏` | 工具栏图标 / 右下角悬浮按钮 / 仅命令唤出 |

## 🛠️ 键盘命令与快捷键

在 EdgeEver 任意界面按下 `Ctrl+P` 或 `Cmd+P` 呼出命令面板：
- **`GitHub 开源热搜日报 (控制台)...`**：呼出双栏可视化控制台，浏览卡片流并由 AI 生成文章；
- **`立即生成昨日 GitHub 开源热搜日报`**：一键在后台拉取热榜、调用 AI 生成并保存笔记；
- **`立即生成本周 GitHub 开源技术周刊`**：一键生成全周开源趋势深度周报。

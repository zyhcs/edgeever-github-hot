# 🚀 EdgeEver GitHub Hot Digest & Benchmark (开源热搜与竞品调研)

面向 [EdgeEver](https://edgeever.org) 笔记系统的 **GitHub 开源热搜、月度特刊与自定义竞品选型调研插件**。

除了类似官方的 AI RSS 分类日报，本插件不仅聚合 GitHub 每日、每周、**最近一月**的开源热榜，更支持**自定义关键词搜索与竞品横向对比调研**（如快速对标类似 EdgeEver 的开源笔记/知识库项目、AI Agent、MCP 等）。借助 **EdgeEver 客户端原生 AI 模型** 或 **自定义 OpenAI 兼容代理**，一键生成结构严谨、排版精良的 Markdown 深度日报或竞品横向对比矩阵报告！

---

## ✨ 核心特性

- 🌅 **三维全周期热搜矩阵**
  - **昨日开源热搜日报 (Daily Digest)**：聚焦过去 24 小时 GitHub 飙升最快的顶级黑马项目；
  - **最近一周技术趋势周刊 (Weekly Digest)**：聚合本周全景技术热度榜 Top 10 ~ Top 20，提炼本周技术风向标；
  - **最近一月开源热搜特刊 (Monthly Digest)**：全面回顾过去 30 天整个开源生态的技术演进脉络与月度最具价值开源项目。
- 🔍 **自定义关键词检索 & 开源对标调研**
  - **自由关键词输入**：支持在弹窗搜索栏输入任何关键词（如 `edgeever`、`markdown note`、`knowledge base`、`pkm`、`local-first`、`ai agent`、`mcp` 等），实时拉取 GitHub 相关开源项目；
  - **常用对标分类标签云**：内置常用预设（`📝 笔记与知识库 (EdgeEver对标)`、`🤖 AI Agent 与工作流` 等），并支持将常用词一键保存为个性化标签，持久化记录在工作区。
- ⚔️ **双重 AI 报告模式：技术速报 vs 竞品横向对比调研**
  - **📊 综合技术热点速报模式**：生态洞察 + 项目精解（痛点、架构亮点、适用场景）+ 全景汇总表；
  - **⚔️ 竞品横向对比与选型调研模式**（专为对标 EdgeEver 等场景量身打造）：
    - 赛道生态现状与核心架构演进脉络（如 Local-First、数据存储、块级富文本模型）；
    - **核心竞品横向对比全景矩阵表 (Markdown Table)**（架构技术栈、离线存储模型、扩展与二次开发能力、核心亮点、局限性与适合人群）；
    - 标杆项目逐一深度评测（与 EdgeEver 或主流标杆产品的核心差异与借鉴点）；
    - 多维度技术选型决策树与落地建议。
- 🤖 **双引擎 AI 智能解读 (免配置 / 高灵活)**
  - **EdgeEver 原生 AI (推荐)**：直接联动客户端已配置的工作区大模型（`context.ai.generate`），开箱即用，无需配置 Key；
  - **自定义 OpenAI 兼容代理**：支持填入自建 DeepSeek、OpenAI、Moonshot 或中转 API 端点与 Key。
- 📁 **自动保存与智能归档**
  - 生成文章一键保存至指定笔记本（自动识别或自选）；
  - 自动注入分类标签（如 `#GitHub热榜`、`#开源日报`、`#开源月刊`、`#竞品调研`、`#技术选型` 等）；
  - 智能防重复机制：同一周期的日报支持无缝原地更新或新立版本。
- ⏰ **定时自动生成 (类似官方 RSS 日报计划)**
  - 支持在设置中开启每日定时任务（如每天上午 `08:30`），在后台自动抓取热榜并通过 AI 撰写日报存入笔记。

## 📥 安装方式

### 方式一：EdgeEver 插件管理器一键安装 (推荐)
1. 打开 EdgeEver，进入 **「设置」 -> 「插件」**；
2. 点击 **「从 GitHub 安装」**，填入本仓库地址：
   ```text
   zyhcs/edgeever-github-hot
   ```
3. 点击安装，插件将自动完成下载与启用！

### 方式二：手动安装
1. 前往本仓库的 [Releases 页面](https://github.com/zyhcs/edgeever-github-hot/releases) 下载最新发行版的 `manifest.json`、`main.js`、`styles.css`；
2. 将这三个文件拷贝至 EdgeEver 插件安装目录即可。

## ⚙️ 设置项指南

| 配置项 | 默认值 | 作用说明 |
| :--- | :--- | :--- |
| **默认榜单统计周期** | `昨日开源热搜日报` | 快捷打开时的默认模式（昨日日报 / 本周周刊 / 最近一月特刊） |
| **默认技术分类** | `🔥 全语言总热榜` | 默认拉取的编程语言或对标专题 |
| **常用自定义对标关键词** | `markdown note, knowledge base, pkm, ai agent, mcp` | 弹窗中常驻的快捷对标标签云 |
| **默认 AI 报告模式** | `综合技术热点速报` | 可选「综合技术热点速报」或「竞品横向对比与选型调研」 |
| **精选项目数量上限** | `10` | 每次交由 AI 深入解读的项目数量（5 ~ 20） |
| **AI 总结引擎** | `EdgeEver 原生 AI` | 选用客户端内置 AI 还是自定义代理 |
| **自定义 AI 端点** | `https://api.openai.com/v1` | 自定义代理 Base URL |
| **自定义 AI Key / Model** | - | 对应 API 密钥与模型名称（如 `gpt-4o-mini` / `deepseek-chat`） |
| **每日自动生成日报** | `关闭` | 是否开启后台定时调度自动写作归档 |
| **自动生成时间** | `08:30` | 每天固定触发日报生成的时刻 |
| **入口按钮位置** | `嵌入编辑器工具栏` | 工具栏图标 / 右下角悬浮按钮 / 仅命令唤出 |

## 🛠️ 键盘命令与快捷键

在 EdgeEver 任意界面按下快捷键 `Cmd + P`（macOS）或 `Ctrl + P`（Windows）：
- **`GitHub 开源热搜与竞品调研 (控制台)...`**：唤出双栏可视化控制台；
- **`立即生成昨日 GitHub 开源热搜日报`**：后台拉取热榜、AI 深度生成并保存笔记；
- **`立即生成本周 GitHub 开源技术周刊`**：一键生成全周技术趋势周报；
- **`立即生成最近一月 GitHub 开源特刊`**：一键生成月度技术演进特刊。
